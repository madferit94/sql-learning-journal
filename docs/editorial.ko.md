## 현재 범위

2026-10-27 Notion 수동 동기화 기준으로 21개 세션·최종 기록 SQL 110개를 포함합니다. Day18~21을 한영으로 추가하고 Day11~20의 최신 정리 내용을 반영했습니다. 대화 경위·붙여넣기 정정 서술·숙련도 평가 문장은 제외하며, 필요한 SQL 오류와 수정 이유·실제 결과·해석 한계는 보존합니다.

한국어판은 상세 원문을 따르고 영어판은 같은 문제·최종 SQL·결과값을 담은 편집 번역입니다. 반복 설명은 축약할 수 있습니다. 금융 고객 ID는 가명 처리하며 비공개 원문·대응표·원본 데이터·덤프·인증정보·개인 경로는 공개하지 않습니다.

## 근거와 게시 검증

결과표는 학습 중 실행 기록입니다. 이번 게시에서는 문서 구조·문제 수·한영 최종 SQL 해시·결과표 대응·링크·코드 블록·개인정보 제외 여부를 검증하며 문제 SQL을 재실행하지 않습니다. Day19 1번에는 나중에 공유된 결과와 당시 읽기 전용 DB 대조 기록을 반영했습니다. F1 적재 검증은 별도 데이터 준비 검증이며 데이터 안내에 구분했습니다.

query-manifest.json은 Day·문제 번호와 최종 SQL 해시를 연결합니다. 이전 시도는 정답 코드가 아닙니다. Day11 3번의 ERROR 1064와 성공한 후속 결과는 보존하며, 특수 공백 원인을 이번 게시에서 별도로 재현하지 않았습니다.

## 해석 주의점

- 한 행의 의미·복합 키·누락·중복 JOIN·날짜 범위·분모를 확인합니다.
- 반복 구매 비율은 코호트 리텐션이나 인과적 충성도 지표가 아닙니다.
- 중간 반올림은 재평균·순위를 바꿀 수 있으므로 문제 조건에 따라 정밀도를 유지합니다.
- 별칭 참조·함수 종속성은 DB별로 다를 수 있습니다.
- 40랩·시간 임계값은 학습용이며 본 레이스 포인트·RANK는 공식 챔피언십과 다릅니다.
