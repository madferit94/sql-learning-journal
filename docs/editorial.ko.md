## 현재 범위

수동 동기화 기준일은 2026-11-08이며 23세션·최종 쿼리 120개입니다. 한글은 노션 상세 기록을 따르고 영어는 동일 문제·최종 SQL·기록된 결과를 포함한 편집 번역입니다. 대화식 평가·붙여넣기 정정 서술은 제외하고 SQL 오류의 원인·수정·해석은 보존합니다.

## 과거 실행과 현재 검증

기존 결과표·실행 시간은 과거 기록입니다. 2026-11-02 재검증에서는 당시 최종 SQL 115개를 데이터 범위·이름 대응을 명시한 환경에서 모두 재실행했습니다. 세부 조건·수치 정정·재현 한계는 [검증 기록](audit.ko.md)과 [쿼리별 결과](audit-results.json)에 있습니다. 원래 오류가 발생한 당시 입력 바이트가 없으면 현재 재실행 성공만으로 과거 원인을 확정하지 않습니다.

query-manifest.json의 최종 SQL 해시는 한글·영문·SQL 파일과 맞춥니다. 이전 시도는 학습 기록이며 실행용 정답으로 취급하지 않습니다. Day11 문제 3은 과거 ERROR 1064와 이후 성공 결과를 함께 보존한 해결 완료 문제입니다.

## 공개 범위와 해석

금융 고객 ID는 기존 가명을 유지합니다. 원본 ID 대응표·데이터·덤프·인증정보·개인 경로·비공개 노션 원문은 게시하지 않습니다. 집계 단위·JOIN 키·NULL·분모·날짜 범위·반올림·경기 범위를 구분합니다. 40랩 조건은 학습용이며 본 레이스 합계나 RANK는 공식 챔피언십 동점 규칙을 대체하지 않습니다. 검증 스크립트는 문서 일치 여부를 검사하고 SQL 실행 증거는 별도 감사 결과에 기록합니다.

Day23 음악 5문제를 추가하고 동일 DB에서 최종 결과표 전체를 대조했습니다. 이는 앞선 115개 쿼리의 재검증을 다시 했다는 뜻은 아닙니다. 예제 따라 입력과 독립 문제 풀이를 구분하고 새 개념은 예제 연습 후 문제에 적용합니다.
